# Project Euler problems about probability and expected value

_Problem coverage last checked: 2026-08-29, through Problem 997. Difficulty ranks and levels last checked: 2026-09-12._

Project Euler does not publish official subject tags. This is therefore a curated, broad list based on the problem statements. A problem is included when probability, expected value, a random process, or the distribution of dice/coin outcomes is central to the model or requested computation. Problems that only use a pseudorandom generator to produce deterministic input are excluded.

This list contains **103 problems**, ordered from easiest to hardest by Project Euler's current rank. A lower rank indicates an easier problem. Rankings and levels are dynamic and may change as members solve additional problems.

## Scope notes

- Included: explicit probability calculations, expectations, random walks/processes, optimal strategies under uncertainty, random permutations/selections, and dice/coin distribution problems.
- Excluded: deterministic problems that merely use a pseudorandom number generator to create input; poker enumeration without a probability question; and deterministic counting problems that mention dice but do not study their outcome distribution.
- Borderline inclusions such as Problems 240, 376, 389, and 423 are retained because their central counting task directly describes a dice probability distribution.
- Direct problem links use Project Euler's preferred URL form: `https://projecteuler.net/problem={problem_id}`.
- Difficulty ranks and levels come from the live **Problem Statistics** panel shown on each Project Euler problem page to signed-in members.
